快橙伴航 1.3.3

本版新增
新版深浅主题、侧栏导航与状态卡片，重新整理主页、运行记录、设置、关于及白名单界面。
主页新增可选“微信直连”开关，默认开启；必须完成组件安装并核验“已生效”。手动关闭会保存，详细范围见“微信直连使用说明.txt”。
Claude出口保护和网络监测保留，分别见随附说明；不会自动启动Claude，不改变项目目录。

此前修复
修复从不同入口打开时，找不到上一次临时代理恢复记录的问题。
GUI、CLI 和新的一键脚本使用 %USERPROFILE%\.OrangeDesk；网络会话位于其中 network\sessions。
首次打开自动导入有效的旧白名单、主题和背景。账号、登录缓存不迁移。
旧应用隔离目录中，只有与当前临时代理地址准确匹配的恢复记录才会采用。
没有有效记录时不强制清空或覆盖代理设置。

单文件版
双击“快橙伴航.exe”直接打开 Qt 界面，白名单、保活、分流和快橙官方安装程序均包含在这个 EXE 中。
不需要旁边放脚本、Python、Qt DLL 或资源文件夹；运行时自动在临时目录释放必要依赖。
白名单、外观和运行记录继续保存在 %USERPROFILE%\.OrangeDesk；关闭后不会丢失白名单。
单文件也能用命令行，例如：
  .\快橙伴航.exe whitelist add example.com --mode direct
  .\快橙伴航.exe whitelist add example.com --mode vpn
  .\快橙伴航.exe whitelist list
  .\快橙伴航.exe status
请不要同时打开安装版和其他位置的单文件版，以免两个入口竞争同一个后台。
快橙的驱动安装、登录和线路选择仍由原厂客户端处理。

安装
双击 OrangeDesk-1.3.3-Setup.exe，按提示完成安装。
默认只装到当前用户，无需管理员权限安装伴航本身。
新电脑尚未安装快橙时，安装末尾可打开随附的官方安装程序。
快橙网络驱动可能需要管理员权限；安装、登录和首次连接按原厂流程完成，需要联网。
本包包含官方安装程序与公共部署文件，不包含任何人的快橙账号或登录缓存。
支持 Windows 10 22H2 / Windows 11 x64；不适用于 macOS、Linux 或 Windows ARM64 原生运行。

界面
打开桌面“快橙伴航”，点击“启动伴航”。
打开快橙并启动连接保活、国内直连与海外访问。
点击底部“快橙”或右上角“快橙”，将官方客户端显示在伴航里，登录、选线路和连接仍由快橙原界面处理。
点击“独立窗口”或正常关闭伴航，会把快橙恢复为原来的独立窗口；不结束快橙进程。
窗口集成识别随包的官方快橙 3.0.0.179。快橙升级为其他版本时，可能需要更新伴航后才能在专用区域显示，独立客户端仍可使用。
原厂窗口随伴航移动与显示，不修改快橙程序、窗口父子关系或 DPI 模式。窗口区域不足时请放大伴航，或点击“独立窗口”。
在“设置”选择浅色／黑夜模式，或切换内置的风景、二次元、宇宙与流光背景；选择会自动保存。
“暂停保活”仅暂停自动连接，国内分流继续生效。
本窗口启动的会话，关闭窗口时停止并恢复之前的系统代理；快橙保留运行。
想继续运行，请选择“后台运行”，再从托盘打开或退出。
切换到其他页面、最小化或转到其他应用时，集成的快橙窗口隐藏；回到“快橙”页面后显示。快橙连接继续运行。
仅打开界面查看一个已由命令行启动的会话，不会接管会话，关闭查看窗口不会将其停止。
保活在快橙已经登录且可连接时自动重连；账号过期、驱动安装或原厂登录弹窗需要在快橙中处理。

白名单：快速固定路线
当前文件夹或便携版双击“白名单设置.cmd”，直接打开编辑器；无需重新安装。
伴航右上角“白名单”、设置页和托盘菜单均可打开。
复制网址后，在伴航窗口内按 Ctrl+L 打开并自动填入域名。
Enter 固定直连；Ctrl+Enter 固定 VPN；Shift+Enter 换行。
伴航窗口内 Ctrl+Shift+D：把剪贴板网址直接加入直连白名单。
伴航窗口内 Ctrl+Shift+P：把剪贴板网址直接加入 VPN 白名单。
托盘菜单也可直接将剪贴板网址设置为直连或 VPN。
“最近连接”每个域名旁的“直连”“VPN”按钮，一次点击即可添加；运行记录也支持右键固定路线。
完整网址按换行或空格分开；纯域名还可用逗号或分号分隔。可一次添加多个网址。
规则只保存域名或 IPv4，不保存网址路径、账号、密码或查询参数。默认包含子域名；IPv4 只匹配该地址。
不自动把 www 域名扩大为整个网站；如果网站使用其他资源域名，可从“最近连接”一键补充，或直接填主域名并勾选“包含子域名”。
用户规则优先于自动国内/海外判断。命中后不再检查国内域名表或国内 IP 归属，但必要的 DNS 和连接仍会进行。
指定 VPN 时不会因解析到国内 IP 改成直连；指定直连时不自动换成 VPN。
未命中继续使用自动分流。更具体的规则优先；同一域名的“仅此域名”优先于“包含子域名”。
运行中的新连接约 1 秒内采用新规则；现有下载/长连接继续原路线，可刷新页面或重新打开软件连接来采用新规则。
规则保存在 %USERPROFILE%\.OrangeDesk\whitelist.json。GUI、CLI 和原一键脚本共用；关闭工具后规则保留，临时分流仍会恢复原设置。
已打开的旧版黑框需要关闭并重新双击更新后的“快橙一键启动.cmd”，才能加载本次白名单能力。
此功能用于遵循 Windows 系统代理的 HTTP/HTTPS 软件，不接管不使用系统代理的 SSH、游戏 UDP 或独立代理。

命令行
安装会自动添加到当前用户 PATH。安装后重新打开终端即可输入：
  orange ui           打开界面
  orange ui --whitelist  直接打开白名单编辑器
  orange whitelist add https://example.com/path       固定直连
  orange whitelist add example.com --mode vpn          固定 VPN
  orange whitelist add example.com --exact             仅匹配该域名
  orange whitelist remove example.com                  删除包含子域名的规则
  orange whitelist list                               查看规则
  orange start        打开快橙并持续保活和分流
  orange status       查看状态
  orange pause        暂停保活，保留分流
  orange resume       恢复保活
  orange stop         停止并恢复启动前的代理设置
  orange logs         查看日志
  orange restore      异常退出后的恢复入口
  orange install-vpn  打开随附的官方快橙安装程序
  orange shutdown     停止会话并退出控制后台
命令行 start 后即使关闭终端，会话仍运行；用 stop 或界面中的停止按钮结束。

分流的范围
使用国内域名、.cn、国内 IPv4 分配记录和局域网规则，物理网卡直连。
海外访问继续使用快橙。OpenAI、ChatGPT 等必要海外服务保留快橙路径。
HTTPS 内容保持端到端加密，不安装证书或解密内容。
分流作用于使用 Windows 系统代理的 HTTP/HTTPS 应用。
应用自身忽略系统代理、使用自己的代理或直接发起 UDP/QUIC 时，不承诺覆盖所有流量。
不是全系统 TUN 分流，不修改快橙私有客户端、默认路由或系统 DNS。
规则快照不保证每个 CDN、国内域名或地理位置都完全正确；一时网络波动也可能来自网站本身。

与原脚本
原来的“快橙一键启动.cmd”仍可使用，但请不要同时运行两套控制。
伴航检测已有会话会提示先结束原会话，不会强制接管或关闭快橙。
卸载伴航会停止其后台、恢复代理、移除本安装添加的 PATH 项，不卸载快橙。

诊断
本地状态：%USERPROFILE%\.OrangeDesk
本次网络运行记录：界面“运行记录”显示的会话目录。
记录访问域名、错误和线路计数，不记录网页正文或账号密码；日志保留在本机。
如果代理恢复失败，保留日志和 proxy-before.json，先用 orange restore。

程序没有商业代码签名证书，Windows 可能显示未知发布者。
随附快橙官方安装程序保持原厂数字签名。请勿关闭系统安全防护。
第三方来源及许可在安装目录 _internal\licenses；对应自编源码和重建脚本另附源码包。

由你检查新版界面
1. 点击底部“快橙”。确认原厂界面出现在专用区域，文字、按钮清晰，能正常选线路或打开设置。已连接时无需为了检查而断开。
2. 移动、放大伴航，切换页面，再回到“快橙”。确认快橙窗口跟随且不遮挡伴航按钮；切换到其他应用后不盖住其他应用。
3. 点击“独立窗口”，确认恢复原快橙窗口。重新在此打开后，正常关闭伴航，确认快橙仍运行，原窗口恢复。
实际快橙界面本次留给你手动检查；开发验证仅使用自建测试窗口，没有操作你的快橙连接、线路或账号。
