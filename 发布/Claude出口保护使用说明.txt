快橙伴航 1.3.3 — Claude 出口保护

如何使用
1. 双击“更新并打开伴航.cmd”，更新完成后伴航会打开。
2. 在快橙中自行连接你选定的新加坡节点；本程序不会切换节点，也不自动核验节点国家。
3. 退出已有的 Claude 会话，再点击伴航的“启动伴航”。
4. 开启主界面的“Claude 出口保护”，阅读确认说明并完成 Windows 管理员授权。
5. 等界面显示“已开启”，在原来的项目文件夹打开终端，照常输入 claude。

开启后做什么
伴航为识别到的原生 claude.exe 添加 Windows 出口限制：新建的非本机连接只能使用开启时确认的 VPN 网卡。VPN 掉线、系统路由退回普通网络时，符合范围的 Claude 连接会被拒绝。
不启动 Claude，不改 PATH、项目目录、终端配置、Claude 凭据或聊天内容，不自动切换节点。
普通网络监测和导出诊断日志功能继续保留，出口保护状态也会收入诊断包。

必须知道的范围
本功能只覆盖界面所识别的原生 claude.exe 路径。Node 脚本版、其它安装位置、新增路径、以及其它程序代发的流量不自动覆盖；更新 Claude 后请检查保护状态和程序路径。
本机回环通信不被阻断；如果 Claude 经其它本地代理转发，本开关无法保证那个代理的外部出口。
开启前请退出已有会话。已经建立的连接不保证能追溯阻断。
规则按程序路径生效，同一台电脑上其他用户运行同一路径的 Claude 也会受影响。
本机出口限制不是账号风控保证，也不证明所选节点的国家或账号使用资格。
网卡重装或 VPN 网卡身份变化后，旧规则可能阻断全部外部连接；请关闭保护、确认节点和伴航状态后重新开启。

如何关闭 / 恢复
关闭“Claude 出口保护”并完成 Windows 管理员授权。只有核验成功后界面才确认关闭。
保护规则持续生效，关闭伴航、停止分流或重启电脑不会自动解除。卸载或删除程序前，请先关闭保护。
若伴航界面打不开，解压保留本更新包，双击“关闭Claude出口保护.cmd”。它只关闭伴航自己的规则，不会启动 Claude 或改 VPN。
也可在本更新包目录手动执行：
  .\快橙伴航.exe claude-protection status --json
  .\快橙伴航.exe claude-protection disable --if-present
若结果不确定，请保留程序与 %USERPROFILE%\.OrangeDesk 中的记录，并导出诊断日志。
